## 11. 建議的關閉順序

```
P0（雲環境／集合／探針／契約測試）
  → P3/P5 雲函數路由（讓 Use Cases 真的可用）
  → P7b-1/2（real API + apiMode）
  → P7b-3~10（Storage／頁面接真資料）
  → P6（支付／退款／分帳／回調／對帳）
  → P8（admin-api／認證／權限／2FA）
  → P7a-2b（預約時段／混合單）
  → 清理 L-1~L-8
```

> **不要先切 `apiMode` 再補 `real`**；也不要先接真實支付再補雲函數路由。
> 每一步都要有可回滾點（commit／tag）。

## 12. 如何維持這份清單

建議每次階段結束時重跑：

```bash
grep -rn "建置中\|notImplemented\|TODO(" pages services utils packages cloudfunctions
```

並人工確認：

- 所有 Toast 佔位是否已由 Use Case 取代
- `services/api/real` 是否仍有 `notImplemented`
- `cloudfunctions/*` 是否仍是健康檢查骨架
- 是否還有本機 Storage 作為唯一資料源
